Quick Guide & Resources

How to Use the Simulator
  1. Select Start: Choose from dropdown or click any Room/Junction on the floor plan.
  2. Manage Hazards: Use the hazard controls panel or Shift+click any node/corridor to block it.
  3. Real-time Route: Green path instantly re-routes to the optimal exit using Dijkstra.
  4. Custom Blueprints: Click "Import Data" to test any custom building layout JSON.
